## About

I'm **Prateek**, a full stack web developer on a mission to build interactive, polished products for the internet. I'm pursuing my **BCA at PSIT Kanpur** (Class of 2028), and I enjoy owning a feature end to end: from the interface a user touches to the logic that powers it.

- **Front-End** — responsive interfaces with HTML, CSS, JavaScript, Bootstrap and React that look right on every screen size
- **Back-End** — server-side logic, APIs and data models with PHP and Laravel, backed by MySQL and MongoDB
- **Product Mindset** — turning rough ideas and frustrating bugs into clean, working features
- **Always Learning** — picking up new tools, collaborating, and building projects that make an impact

**Open To:** `Collaboration` · `Internships` · `Freelance Projects` · `Open Source`
